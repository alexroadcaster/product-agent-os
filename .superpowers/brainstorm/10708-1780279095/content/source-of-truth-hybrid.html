Hybrid Source-of-Truth Model

HTML becomes the user's canonical project cockpit, while edits still flow through typed artifacts, proposals, and approval.

Proposed Product-Agent OS source model
Layer 1

Project Cockpit HTML

Single user-facing source for navigation, project state, diagrams, document map, graph, stats, and pending decisions.

Allowed: read, filter, inspect, select, create proposal.

Forbidden: silent direct mutation.

Layer 2

Typed Ledger / Patch Proposals

Every dashboard action writes structured intent: update document, accept gap, add source, stage graph refresh, request approval.

Proposal records carry owner, target files, risk, rollback, and verification command.

Layer 3

Durable Project Artifacts

Markdown, JSON, Mermaid, OpenAPI, AsyncAPI, DBML, PlantUML, MkDocs and run evidence remain typed backing stores.

Approved proposals sync back here.

Result

The user lives in one panel, but the system keeps auditability, diffs, approvals, rollback and source policy.
