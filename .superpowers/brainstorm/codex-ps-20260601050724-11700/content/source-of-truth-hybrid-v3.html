Hybrid Source-of-Truth Model

HTML becomes the user's canonical project cockpit, while edits still flow through typed artifacts, proposals, and approval.

Variant C: Product-Agent OS project cockpit
User Source

Project Cockpit HTML

One panel for project status, pages, diagrams, document inventory, graph map, stats, questions, and pending decisions.

Reads: generated cockpit packet, graph JSON, document registry.

Writes: only typed intents.

Write Boundary

Typed Ledger / Patch Proposals

Every cockpit action becomes a structured proposal with target files, owner, approval state, rollback and verification command.

No silent mutation of Markdown, JSON, MkDocs, Swagger/OpenAPI, PlantUML or DBML files.

Backing Stores

Durable Project Artifacts

AGENTS, REQUIREMENTS, PLAN, TEST, EVALS, RUNLOG, docs, source registry, diagrams and contracts remain diffable backing stores.

Approved proposals sync back, then cockpit regenerates.

Graph

Graphology builds the artifact relationship graph; sigma.js renders an offline interactive map.

Safety

HTML is authoritative for operator navigation and state review, not a bypass around approvals, tests, source registry or versioned docs.
