## Общая среда и проекты

Путь чтения: состояние → причина → действие. Portfolio показывает все проекты, общий объём оставшейся работы, распределение расхода и активность. Из него можно перейти к выбранному проекту. Область статистики видна в заголовке. Три демонстрационных проекта используют единый набор записей: portfolio total равен сумме project totals. Agent totals — другой разрез тех же записей; складывать их с project totals нельзя.

Внутри проекта сохраняются 14 назначений: Обзор, Задачи, Сессии, Агенты, Скиллы, Карта проекта, Документы, Проверки, Автономность, Решения, Поиск, Импорт, Резервная копия, Настройки. Выбор проекта выше навигации. Лаборатория и панель просмотра принадлежат альбому, а не продуктовому меню.

**Обзор проекта** — dashboard прогресса, оставшихся задач, очереди и нагрузки агентов. Показатели имеют период; очередь показывает порядок и причину ожидания. Расход выделен отдельно. Прогресс означает долю выполненных задач, а не процент готовности всего продукта. Отменённые задачи не считаются выполненными; успешный run не равен принятой задаче. Неизвестные оценки нельзя использовать как нулевые при взвешивании.

**Агенты** — общий dashboard запусков, исходов, задач и расхода; выбор конкретного агента открывает его разрез. Профиль, редактирование, история и активность сохраняются. Нагрузка — активные запуски/назначения, не CPU и не «эффективность». Различие расхода не доказывает качество: задачи могут иметь разную сложность.

## Токеномика

| Значение | Смысл |
| --- | --- |
| Input | Все входные токены, включая cached input |
| Output | Выходные токены |
| Total | Input + Output, cache второй раз не добавляется |
| Cached input | Подмножество input, отдельная диагностическая величина |
| tool_use | Число вызовов инструментов; отдельно от токенов и денег |
| Cost | Условная сумма synthetic receipt в USD, не тариф провайдера |
| Coverage | Доля записей с измерением; partial/unknown видны |

Альбом различает демонстрационную аналитику и текущую доступность данных. По `team/service.mts` duration/token/cost возвращаются null; task/project usage и aggregate tool_use не подтверждены. Поэтому числовые графики подписаны как synthetic fixtures; режим доступности не подключается к сервису и не подменяет unknown нулями. В fixture есть отдельные unknown и explicit zero записи.

Будущая интеграция требует источника usage, периода, единиц, валюты, timestamp, revision и coverage. Пока данных нет, UI показывает unavailable. Сбор/хранение телеметрии и расчёт биллинга — отдельный функциональный scope за пределами редизайна. Cost в макете не основан на предполагаемых ценах моделей.

## Полная карточка задачи

Один клик выбирает строку; двойной открывает большую карточку поверх списка/доски. Есть явная кнопка и клавиатурное открытие. Исходная поверхность остаётся на месте. Dialog ограничен высотой viewport, прокручивается внутри; заголовок и закрытие доступны. Escape закрывает, focus trap удерживает клавиатуру внутри и возвращает фокус к источнику открытия.

Описание, ценность и критерии читаются в широкой области; тип, приоритет, родитель, сроки и процесс — рядом. Редкие подробности раскрываются, но не удаляются ради компактности. [Карта полей](design/2026-11-13-v3/task-field-map.md) является обязательным checklist: все поля Editor, files/fileContexts, assignments, artifacts, blocker/reason; read-only creator/duration/hierarchy/revision отдельно.

Сохраняются восемь вкладок: Описание, Файлы, Критерии, Комментарии, История, Вложения, Связи, Сессии. Расход — дополнительная концепция. Create/move/delete, components, versions, release policy, columns/archive остаются в каталоге. Статус меняется через preview и guards; процесс существующей задачи закреплён и меняется через migration preview. Макет не обещает обход этих ограничений или реальное сохранение. Dirty draft и revision conflict повторно проверяются на app baseline при внедрении.

## Карта проекта

1. **Граф D3**: узлы/связи, выбор, zoom, fit/reset и фильтр модуля. Раскладка стабилизируется; фонового дрейфа нет. Кнопки и список обеспечивают альтернативу drag.
2. **Mermaid**: текущий снимок целиком либо модуль, реально отрендеренный SVG и читаемый исходный текст. Strict security сохраняется; Tiny использует Dagre.
3. **Список**: точный поиск, source/context и связанные объекты.

«Целиком» означает все узлы данного snapshot. Реальная карта — partial lexical relations с revision/stale/coverage; она не доказывает runtime dependency/impact. Синтетическая V3-схема не заменяет источник истины.

## Цвет, иконки и плотность

| Основа | Porcelain | Obsidian |
| --- | --- | --- |
| Canvas | `#F4F5F7` | `#14171C` |
| Surface | `#FCFCFD` | `#1D222A` |
| Text | `#20242D` | `#EEF1F7` |
| Accent | `#3366F4` | `#90B4FF` |

Точные цвета принадлежат [tokens.css](design/2026-11-13-v3/tokens.css) и theme blocks. Цветные двухтонные Duoicons отличают назначения; малые служебные стрелки нейтральны. Статусы имеют подписи, цвет не единственный канал. Нет emoji вместо иконок. Лицензия выбранной коллекции проверена отдельно от лицензии каталога icons0.

System sans поддерживает кириллицу; controls около 14px, чтение 16px, заголовки около 24px. Числа — tabular numerals. Интервалы 4/8/12/16/24, строки около 40–44px, controls 32–36px. Desktop 1280/1440/1920. Body не расширяется, длинные пути переносятся. `min-width:0` и `minmax(0,1fr)` позволяют панелям сжиматься. Локальный scroll допустим для карты/code/доски; формы не требуют горизонтального scroll.

## Переходы и состояния

Левое меню использует адаптацию [Sidebar collapse](https://designbookmark.com/motion#db-sidebar-collapse): кнопка вверху сворачивает 216px sidebar в 64px rail, рабочая область расширяется. Цветные иконки сохраняются; tooltip доступен мышью и клавиатурой. При раскрытии подписи сдвигаются на 10px и появляются каскадом (60ms + 40ms на элемент), стрелка поворачивается на 180°, подсветка пружинно следует выбранному разделу. Stiffness/damping исходника сохранены: width 260/24, rotation 300/22, selection 380/28, labels 300/26. Состояние сохраняется при переходах внутри альбома; после перезагрузки меню открыто. Reduced motion переключает сразу, без пружин. Showcase autoplay не перенесён; фонового animation loop после завершения нет. Новых зависимостей нет.

GSAP управляет коротким входом поверхности/dialog; CSS — hover/focus; D3 — геометрией chart/graph. Они не анимируют одно свойство одновременно. Старые animations очищаются при смене маршрута. Reduced motion сохраняет текст и выбранность без движения. Ориентир: 160–220ms для поверхности, 180–240ms для dialog; это наша спецификация, не измерение конкурентов.

Skeleton повторяет итоговую геометрию; error даёт повтор, empty объясняет отсутствие данных, stale сохраняет контекст. Progress показывает процент только при измеримом объёме. Toast не заменяет validation рядом с полем. Пауза, ожидание решения и остановка имеют разные подписи. Важные действия не используют магнитное движение, scroll hijacking или декоративные бесконечные эффекты.

[DesignBookmark Motion](https://designbookmark.com/motion) использован для принципов tab pill, segmented control, expand card, loading-to-success. Код каталога не копировался. D3, GSAP и Mermaid действительно подключены локально; renderer activation проверяется отдельно от факта установки. Bundle около 3.26MB приемлем для offline альбома; внедрение потребует выборочных imports/lazy loading и измерений.

## Остальные экраны и внедрение

Все 80 образцов V2 сохраняются: уровни sessions; agents/skills profile/edit/history/activity; generation/discovery/import; documents/proposal/diff; checks; policy/pause/reserved runs; decisions/search/import/export/backup/restore. Настройки разделены на среду, проект, подключение, процессы, выполнение и очередь. Preview/confirmation не исчезают. Новые аналитические поверхности добавляются в coverage.

[UI-01–UI-12](design/2026-11-13-v3/implementation-plan.md) остаются planned. Сначала human approval компоновки и field parity, затем tokens/shell, task dialog, analytics presentation, graph, motion/a11y и регрессия. UI-карточки не разрешают backend telemetry, публикацию или Git.

Gates альбома: обе темы и все routes, отсутствие root overflow на трёх ширинах, согласованность fixtures, фактический D3/Mermaid render, dblclick/keyboard dialog, focus/reduced motion. Результаты принадлежат verification. Полная WCAG-сертификация, production performance и human acceptance из этих проверок не следуют.
