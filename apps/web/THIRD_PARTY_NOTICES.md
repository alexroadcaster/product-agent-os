# UI dependencies

Source status: installed local packages and approved V3 source inventory, 2026-11-13.

- D3 7.9.2 — ISC; selected scales/force geometry, no telemetry.
- GSAP 3.15.1 — GSAP Standard License (not MIT); route transition with cleanup. License: https://gsap.com/standard-license/
- Mermaid Tiny 12.3.0 — MIT; local lazy script, strict rendering, no CDN.
- Duoicons — MIT, fernandcf; selected SVG from @iconify-json/duo-icons 1.2.2 (collection version1.1.4), source https://github.com/fazdiu/duo-icons.
- Sidebar springs adapted from https://designbookmark.com/motion-src/sidebar-collapse/side.js and shared motion.js, CSS tokens. Same physical coefficients; product React integration.

Dependency license texts retained in installed package metadata and the existing [V3 notices](../../design/2026-11-13-v3/vendor/THIRD-PARTY-NOTICES.txt). This application does not embed the prototype bundle.
