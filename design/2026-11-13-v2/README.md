# Альбом Product-Agent OS V2

Source status: local synthetic design prototype; needs_user_acceptance, 13.11.2026.

Откройте **index.html в браузере**. Установка, dev server и подключение к приложению не нужны. Полоса «Дизайн V2» внизу — управление альбомом, а не часть будущего продукта.

1. «Все экраны» открывает каталог. Найдите раздел или вкладку по названию.
2. Стрелки переключают соседние образцы. Светлая Porcelain и тёмная Obsidian показывают один и тот же экран.
3. «Состояние» включает loading, empty, error или stale для оценки обратной связи. Это симуляция.
4. [Галерея снимков](contact-sheet.html) показывает весь набор статических изображений.
5. В «Компоненты и состояния» и «Движение и обратная связь» можно проверить controls и motion. Для reduced motion используйте настройку ОС/браузера.

[Короткая запись движения](screenshots/motion-demo.webm) позволяет посмотреть анимации без переключения состояний вручную. В каталоге 160 основных снимков; дополнительно сохранены 8 примеров loading/empty/error/stale в папке screenshots.

Для утверждения сначала сравните задачи, сессии и редактор процессов в обеих темах. Затем пройдите все разделы и вложенные вкладки через каталог. Замечания удобно записывать с screen ID из URL: например `task-summary` или `motion-lab`. Разные screen IDs представляют текущие вкладки, существующие панели либо предложенное разделение длинной формы; происхождение указано в [coverage.json](coverage.json).

В прототипе используется синтетический проект. Кнопки, похожие на сохранение/запуск/удаление/восстановление, демонстрируют UI и не вызывают PAOS API. Экраны не являются доказательством работы этих операций. Обычные визуальные взаимодействия (выбор вкладки, раскрытие, проверка полей) доступны локально.

[DESIGN.md](../../DESIGN.md) — текущий контракт; [research.md](research.md) — источники и решения; [implementation-plan.md](implementation-plan.md) — будущие задачи; [verification.md](verification.md) — выполненные проверки и ограничения. Два concept PNG являются art direction; точные экраны для просмотра находятся в HTML и screenshots.
