# Retrieval, bounds and budgets

Source status: repository_source / static_contract_review; 2026-11-15.

Owner: retrieval/graph owner + docs-maintainer. Scope: DG05, revision `61f6cd4cd048be478e88e2406c733f98b60bc434`. Update when index, filters, budgets, provenance or eval contract changes. Test links do not claim a new run.

[semantic](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_semantic.py) validates index and request, and compares fingerprints when a graph is supplied; it filters records and ranks cosine of locally hashed vectors plus deterministic term-overlap rerank. This is not a trained embedding model or external cross-encoder. Defaults: 25 results, query text up to 160 characters, response limit default 1200 approximate tokens from approval policy; the packet truncates nodes and reports truncation/omitted count. max_query_ms in eval policy is an evaluation threshold, not a runtime guarantee.

With valid prerequisites [hybrid](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_hybrid_retrieval.py) fuses static, semantic and graph candidates; default max_candidates is 20 per component, explainable weighted scores static 1.0 / semantic 1.5 / graph 0.5; external reranker is disabled in the local result. Default packet: 25 results, 4000 approximate tokens; query text up to 120 characters. Do not confuse these defaults with a separate eval threshold, often 1200 tokens.

[embedding gate](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_embedding_provider.py) and [reranker gate](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_reranker_provider.py) describe consent, redaction, budgets, eval and disable/fallback; a gate makes no external call. Separate runtime invocation approval is required before payload transfer. Invalid/stale inputs yield blocked; the packet names fallback (`lexical_or_graph_search` or `semantic_retrieval_or_graph_only`) and does not prove automatic execution of another path.
