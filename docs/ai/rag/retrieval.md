# Retrieval, ограничения и бюджеты

Source status: repository_source / static_contract_review; 15.11.2026.

Владелец: retrieval/graph owner + docs-maintainer. Scope: DG05, revision `61f6cd4cd048be478e88e2406c733f98b60bc434`. Обновлять при изменении индекса, фильтров, бюджетов, provenance или eval contract. Ссылки на тесты не означают нового прогона.

[semantic](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_semantic.py) проверяет индекс и запрос, при наличии graph сравнивает fingerprint; затем фильтрует записи и ранжирует cosine локальных hashed vectors плюс детерминированный term overlap rerank. Это не обученная embedding-модель или внешний cross-encoder. Default: 25 результатов, query text до 160 символов, лимит ответа default 1200 приблизительных tokens из approval policy; packet усекает nodes и показывает truncation/omitted count. max_query_ms в eval policy — порог проверки, не runtime guarantee.

[hybrid](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_hybrid_retrieval.py) при валидных prerequisites объединяет static, semantic и graph candidates; default max_candidates 20 на компонент, explainable weighted scores static 1.0 / semantic 1.5 / graph 0.5; внешний reranker в локальном результате disabled. Default packet: 25 результатов, 4000 приблизительных tokens; query text до 120 символов. Не путайте эти defaults с отдельным eval threshold, часто 1200 tokens.

[embedding gate](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_embedding_provider.py) и [reranker gate](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/plugins/product-agent-os/scripts/product_agent_os/project_graph_reranker_provider.py) описывают consent, redaction, budgets, eval и disable/fallback; gate не выполняет внешний вызов. Отдельный runtime invocation approval необходим до передачи payload. При invalid/stale inputs query возвращает blocked; fallback указан в packet (`lexical_or_graph_search` или `semantic_retrieval_or_graph_only`) и не доказывает автоматический запуск другого пути. [provider tests](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/tests/product_agent_os/test_project_graph_embedding_provider.py), [semantic tests](https://github.com/alexroadcaster/product-agent-os/blob/61f6cd4cd048be478e88e2406c733f98b60bc434/tests/product_agent_os/test_project_graph_semantic.py).
