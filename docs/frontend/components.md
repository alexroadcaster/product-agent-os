## Документы и task backlinks — FUNC-02

В текущем checkout `ArtifactExplorer.links(item)` читает `item.taskReferences` рядом с `taskIds`. Кнопка связанной задачи различает «revision совпадает», «ссылка устарела», «revision неизвестна» и «источник недоступен»; переход использует ID уже найденной задачи. Это состояние task-to-document relationship, не переименование документа и не автоматический refresh task pin. Документ может иметь текущий observed source, тогда как backlink задачи остаётся stale.

Backend catalog/task reference resolution переиспользуют F28 normalization для `files`, `fileContexts`, structured `artifacts.reference` и legacy `artifactReferences`. Structured-only ссылка участвует в фильтре каталога `taskId` и backlinks; внешние URL не интерпретируются как local paths. Для `workspace_file` документа `source.version` и legacy task pin `revision` — raw-byte SHA256, а `fileRevision` — отдельный metadata/policy pin; entity revision и `entity:N` sources сохраняют собственную семантику. Registry `rootIdentity` и `policyVersion` не выдаются за content hash. Полные состояния и query boundaries описаны в [queries/impact](../code-intelligence/queries-impact.md#func-02--явные-ссылки-задачи-и-документы).

Reader сохраняет `available`/`stale`/`unavailable` отдельно от relationship states. Stale pin не подменяется новым content; missing/excluded/moved/deleted source не приобретает права чтения из-за существующей ссылки задачи. Содержимое читается через текущий registry root/policy; чувствительные paths/private-key data не раскрываются, разрешённый document display использует redaction. F02 не запускает graph providers, discovery, migrations или файлы проекта.

Root service/API evidence `.tmp/func-g03/f02-focused-final.log` — **21/21,0skip**, включая новые structured-reference/URL и stale-policy/deleted regressions. UI labels/rendering проверены здесь статически по текущему `ArtifactExplorer.tsx`; текущая browser-приёмка ещё принадлежит root FUNC-G03 и не заменяется service tests. F26/F27 и human acceptance этим разделом не закрываются.
