## Local browser session

[session-gate](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/http/session-gate.mts) accepts only a configured HTTP origin on `127.0.0.1`, checks URL, Host, forwarded headers, cross-site and Origin; Origin is mandatory for mutations. Pairing issues a one-time code valid for 60 seconds and allows at most five attempts; issuing a new code clears sessions. The cookie is HttpOnly and SameSite=Strict; sessions are in memory, expire after 30 minutes idle or 8 hours, and are capped at 64; restart/re-pair invalidates them. Mutations require a CSRF header. This is the particular gate contract, not a guarantee about every client or host protection. [application](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/http/application.mts) uses the gate; [service access tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/service-access.test.mts) and [desktop tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/desktop-local.test.mts) are test routes.

## Routes and secrets

[LLM routes](../ai/llm/routes.md) distinguishes App and BYOK without automatic fallback. [connection broker](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/broker.ts) performs explicit API-key login and account/read; successful login does not prove model access. Remember requires secure store; [Windows credential store](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/windows-credential-store.ts) sends the secret to the bridge via stdin, constrains targets and consumes stdout privately. [profile identity](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/profile-identity.mts) confines targets to the current profile namespace and rechecks identity. Gateway disconnect without forget does not establish credential deletion; explicit forget invokes deletion and failure returns unverified. The broker retains a private set of earlier secrets for redaction of late frames.

[connection tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/connections.test.mts), [profile tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/profile-identity.test.mts), and [gateway tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/app-agent-gateway.test.mts) are related checks, not a new login or access to real credentials. App channel capability/lease differ from browser cookie; see the [threat model](threat-model.md). Do not put secrets in URLs, docs or reports.
