## Local browser session

[session-gate](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/http/session-gate.mts) принимает только настроенный origin вида HTTP на `127.0.0.1`, проверяет URL, Host, forwarded headers, cross-site и Origin; для мутаций Origin обязателен. Pairing выдаёт одноразовый код на 60 секунд, максимум пять попыток; новая выдача очищает сессии. Cookie — HttpOnly и SameSite=Strict; сессии хранятся в памяти, истекают после 30 минут бездействия или 8 часов, ограничены 64; restart/re-pair инвалидирует их. Мутация требует CSRF header. Это контракт конкретного gate, не гарантия всех клиентов или защиты хоста. [application](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/http/application.mts) использует gate; [service access tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/service-access.test.mts) и [desktop tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/desktop-local.test.mts) — тестовые маршруты.

## Маршруты и секреты

[LLM routes](../ai/llm/routes.md) различает App и BYOK без автоматического fallback. [connection broker](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/broker.ts) запускает явный API-key login и account/read; успешный login не доказывает model access. Remember требует secure store; [Windows credential store](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/windows-credential-store.ts) передаёт secret bridge через stdin, с ограничением target и private stdout. [profile identity](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/apps/local-service/src/connections/profile-identity.mts) ограничивает target текущим profile namespace и повторно проверяет identity. Gateway disconnect без forget не доказывает удаления credential; явный forget вызывает удаление, ошибка возвращает unverified. Broker хранит приватный набор прежних secrets для redaction поздних кадров.

[connection tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/connections.test.mts), [profile tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/profile-identity.test.mts), [gateway tests](https://github.com/alexroadcaster/product-agent-os/blob/259977f3b257ba7fc0e932396f8963262bd327ad/tests/web/app-agent-gateway.test.mts) — связанные проверки, не новый вход или доступ к реальным credentials. App channel capability/lease отличаются от browser cookie; см. [модель угроз](threat-model.md). Не помещайте секреты в URL, docs или отчёты.
