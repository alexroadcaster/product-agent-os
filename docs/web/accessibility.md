# Доступность, языки и темы Web

Source status: project-authored / bounded local technical verification; PAOS-0029, 2026-11-12.

В Settings выберите русский или английский язык и Light, Dark либо System, затем сохраните настройки. System следует системному предпочтению цвета. Пользовательские названия задач, workflow, пути, идентификаторы и тексты документов сохраняются в исходном виде. Технические коды ошибок и schema keys также могут оставаться на английском.

## Управление с клавиатуры

| Действие | Управление |
| --- | --- |
| Перейти к основному содержимому | Tab до ссылки пропуска навигации, затем Enter |
| Открыть раздел или карточку | Tab / Shift+Tab, затем Enter или Space |
| Прокрутить Kanban | Перевести фокус на область доски, использовать стрелки; карточки также доступны в списке |
| Переместить задачу | Открыть карточку, выбрать колонку в поле перемещения; если колонка содержит несколько статусов, выбрать статус в диалоге. Переход проходит существующие проверки и отдельное подтверждение |
| Переключить вкладки задачи | Tab до выбранной вкладки, стрелки, Home / End |
| Закрыть диалог выбора статуса | Escape; фокус возвращается к полю перемещения. Tab / Shift+Tab остаются внутри диалога |
| Закрыть мобильную навигацию | Escape возвращает фокус к Menu; переход к содержимому закрывает навигацию |
| Изменить workflow | Tab до поля, обычный ввод и выбор значений; Enter на кнопке сохранения сохраняет черновик. Публикация и запуск выполняются отдельно |
| Читать длинную переписку | Перевести фокус на область сообщений; использовать стрелки и PageUp / PageDown |

На узком экране поля и действия переносятся на новые строки. Доска, граф и некоторые таблицы сохраняют собственную прокрутку, необходимую для пространственных данных. Длинное название проекта сокращается в верхней панели; полное значение доступно в подсказке и выборе проекта.

## Проверка и её границы

Стенд `tests/web/accessibility/browser-acceptance.mts` использует production build и одноразовый локальный service с синтетическими данными. Матрица сопоставляет S01–S26 с существующими функциональными состояниями интерфейса, включая редакторы внутри Settings, и проверяет восемь вкладок задачи в RU/EN × Light/Dark при ширине 1440 и 320 CSS px. Это соответствие состояниям, а не утверждение о наличии 26 отдельных URL.

Автоматические проверки охватывают доступные имена через Chromium Accessibility Tree, контраст вычисленных RGB цветов, границы полей, фокус и перекрытие действий, reflow, управление диалогом и клавиатурой. Отдельные сценарии проверяют пустые данные, loading / unavailable / recovery, System и forced colors. Исходники и build фиксируются хешами до и после прогона; внешние запросы запрещены. Команды, receipts, найденные дефекты и ограничения находятся в отчёте PAOS-0029: `research/product-agent-os-web-m4-0029-execution-2026-11-12.md` (repository-root path).

Порог контраста текста — 4.5:1 для обычного и 3:1 для крупного текста; границы активных полей проверяются от 3:1. Основание — [WCAG 2.2](https://www.w3.org/TR/WCAG22/). RGB-проверка не охватывает весь native paint, градиенты, placeholder и все режимы assistive technology. Проверка forced colors подтверждает доступность фокуса в Chromium, а не эквивалентность всех сочетаний ОС и браузеров. Ручная приёмка со screen reader и полная сертификация соответствия WCAG не заявлены.

При недоступности service сохраните текст несохранённого черновика до перезагрузки страницы. Используйте Refresh либо повторный переход в раздел после восстановления связи; ошибки не означают успешного сохранения. Не включайте provider или native execution для проверки внешнего вида.
