## Scan Method

Owned-source counts use path metadata only, with `rg --files` and recursive exclusions. The important rule is to exclude nested folders with `!**/folder/**`, not only `!folder/**`.

Representative recursive exclusions:

```text
!**/node_modules/**
!**/.git/**
!**/.next/**
!**/dist/**
!**/build/**
!**/site/**
!**/coverage/**
!**/.venv/**
!**/.pytest_cache/**
!**/.ruff_cache/**
!**/.codex-tmp/**
!**/graphify-out/**
!**/*.tsbuildinfo
```

Hidden and ignored state discovery used path metadata only with `--hidden --no-ignore` to identify denylist surfaces. Some ignored `myPartners` temporary test directories returned access-denied errors; they are excluded runtime/test state and remain out of scope for fixture copying.

Pattern scans for sensitive terms were used only as `--files-with-matches` checks. Matched lines, values, secrets, raw prompts, raw messages, and payload bodies were not captured in this artifact.
