    Offline installer — PAOS-AUD-G5¶

    tools/docs_install.ps1 -Install -OfflineWheelhouse <path> использует только локальный wheelhouse и bundled ensurepip при создании venv. Offline имеет приоритет над -AllowNetwork; upgrade pip выполняется только в online ветке. При отсутствии каталога или совместимых wheels команда завершается ошибкой без network fallback. Без -Install команда выводит план; сама установка требует отдельной authority. Проверки G5 подменяют subprocess boundary и ничего не устанавливают.
